# OIO Sync

OIO Lab V1 monorepo scaffold.

## Apps

- `apps/web`: Vue 3 + Vite frontend prototype
- `apps/mock-api`: mock REST API for local integration
- `packages/contracts`: shared zod contracts and TypeScript types

## Scripts

- `pnpm dev:web`
- `pnpm dev:api`
- `pnpm build`
- `pnpm test`
- `pnpm typecheck`
